# Demo audio credits

The current demo uses only short mouse clicks and keyboard taps. It contains no background music, humming, chanting, vocals, or musical notification cues.

- Mouse click: Kenney UI audio, bundled with the brag skill. CC0/public domain. https://kenney.nl/
- Keyboard taps: Keyboard Soundpack #1 by unicae_games. CC0. https://opengameart.org/content/keyboard-soundpack-1-typing-and-single-keystrokes

Effects are synchronized with the illustrated copy, focus, shortcut, and answer actions. Their timing is editorial; the video is not a recording of operating-system audio. These credits replace the earlier humming-track credits, which no longer apply to the current export.
